# 8051 Seven Segment Led

## Description
Displayed numbers 0 to 9
using AT89C51 microcontroller.

## Hardware Components
- AT89C51 Microcontroller
- Seven Segment LED connected to P2
## Tools Used
- Keil uVision C51 (Compiler)
- Proteus 8 Professional (Simulation)

## How it Works
- Using Hex value In Seven Segment led Numbers are Displayed from 0 to 09
