# 8051 LED Switch Control

## Description
Single switch controls LED ON/OFF 
using AT89C51 microcontroller.

## Hardware Components
- AT89C51 Microcontroller
- LED connected to P1.0
- Switch connected to P2.0

## Tools Used
- Keil uVision C51 (Compiler)
- Proteus 8 Professional (Simulation)

## How it Works
- Switch pressed  → LED ON
- Switch released → LED OFF
