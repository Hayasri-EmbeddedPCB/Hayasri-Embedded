# 8051 ALTERNATIVE LED 

## Description
Alternative LED ON/OFF 
using AT89C51 microcontroller.

## Hardware Components
- AT89C51 Microcontroller
- LED connected to Port 2
-

## Tools Used
- Keil uVision C51 (Compiler)
- Proteus 8 Professional (Simulation)

## How it Works
- Using delay function 8 led glow alternatively
