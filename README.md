# Hayasri — Embedded Systems Portfolio

Hi, I'm Hayasri, an embedded systems student building a strong foundation in microcontroller programming and hardware interfacing. This repository documents my hands-on learning journey — from C fundamentals to 8051, PIC16F877A, and ARM (LPC2148) microcontroller projects — as I work toward pursuing an **MS in Embedded Systems in Taiwan (2027)**.

Each project here is written, tested in simulation (Proteus), debugged, and documented — not just copied code, but code I understand well enough to explain and fix.

---

## 🎯 Goal

Building a solid, demonstrable foundation in embedded C and microcontroller peripherals ahead of graduate study, with a focus on:
- Low-level hardware interfacing (GPIO, timers, communication protocols)
- Writing clean, well-documented embedded C
- Progressing from 8-bit (8051, PIC) to 32-bit ARM architecture
- Debugging real compiler/hardware issues, not just following tutorials

---

## 📂 Repository Structure

### `/C` — C Programming Fundamentals
Core language concepts practiced before moving to microcontroller-specific code: Arrays, 2D Arrays, Pointers, Strings, Structures & Unions, Operators, Conditionals, Variables, and Function calling (by value / by reference).

### `/8051_Microcontroller` — 8051 Microcontroller Projects
Peripheral interfacing on the 8051: GPIO/LED control, DC motor control, Stepper motor, Timers, Interrupts, UART serial communication, I2C, ADC, and Seven-segment display.

### `/PIC16F877A` — PIC16F877A Microcontroller Projects
Peripheral interfacing on the PIC16F877A using MPLAB IDE + HI-TECH C: LED control, 16x2 LCD interfacing, Stepper motor (wave drive & half-step sequences). Each project folder includes source code, a project-specific README explaining the logic, and simulation output (screenshots/video) from Proteus.

### `/ARM_LPC2148` — ARM7 (LPC2148) Projects *(in progress)*
Moving from 8-bit microcontrollers to the 32-bit ARM7TDMI-based LPC2148. Planned peripheral coverage:
- **ADC** — Analog-to-digital conversion
- **Timer** — Timer/counter modules
- **PLL** — Phase-Locked Loop clock configuration
- **UART** — Serial communication
- **I2C** — Inter-Integrated Circuit protocol
- **SPI** — Serial Peripheral Interface protocol

Each will follow the same structure as the other folders: source code, README with explanation, and simulation proof.
